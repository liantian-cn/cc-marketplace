# humanizer-zh-next

去除中文文本中由人工智能生成的痕迹。在编辑或审阅文本时使用该功能，可使文本更自然、更像人工撰写的作品。

基于 `op7418/humanizer-zh` 与 `blader/humanizer` 面向中文写作重新适配：吸收英文版中的检测模式，按中文写作习惯重写触发词、示例与修复策略，遵循「改写而非删除、等量覆盖」原则，按 **初稿 → 自检 → 终稿** 的流程工作。

## 安装

```bash
/plugin marketplace add liantian-cn/cc-marketplace
/plugin install humanizer-zh-next
```

## 使用

安装后直接把文本交给它即可，例如「帮我把这段文字去一下 AI 味 / humanize / 润色，改得像人写的」。

技能会先判断文本体裁（个人叙事 / 通用说明 / 营销 / 技术文档 / 学术法律等），再按 33 类 AI 写作模式逐一识别并改写，保留事实、立场与作者意图；个人叙事如需补写细节，会在终稿后以「待核实内容」逐项列出。

## 特性

- 体裁决策矩阵：不同文本用不同处理标准
- 33 类中文 AI 写作痕迹检测与修复（空泛拔高、宣传腔、三段式、破折号堆叠、伪口语化等）
- 语气校准：可提供个人写作样本匹配声音
- 检测指南：区分假阳性，避免误伤正常好文
- 支持初稿 → 自检 → 终稿的交付流程与「待核实内容」清单
