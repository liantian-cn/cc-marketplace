# github-search

基于 [grep.app](https://grep.app) 的 GitHub 代码搜索 MCP 服务器：跨海量开源仓库搜索代码片段、函数定义与用法示例，无需 API Key。

## 安装

```bash
/plugin marketplace add liantian-cn/cc-marketplace
/plugin install github-search
```

## 使用

无需环境变量。安装后运行 `/mcp` 确认 `gh_grep` 已连接，然后提问，例如「在 GitHub 开源仓库里搜索 python 读取 excel 的示例代码」。
