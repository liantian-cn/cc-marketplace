# guizang-ppt

网页 PPT 生成技能（源自 [歸藏 guizang-ppt-skill](https://github.com/op7418/guizang-ppt-skill)）：生成**单文件 HTML** 的横向翻页演示 PPT，含 WebGL 背景、章节幕封、数据大字报、图片网格等模板，支持两套视觉风格：

- **电子杂志 × 电子墨水**：衬线字体 + 流体背景 + 暖色
- **瑞士国际主义**：无衬线字体 + 网格点阵 + IKB / 柠檬黄 / 柠檬绿 / 安全橙高亮

## 安装

```bash
/plugin marketplace add liantian-cn/cc-marketplace
/plugin install guizang-ppt
```

## 使用

安装后提问即可，例如「帮我做一个产品发布会的网页 PPT」「用瑞士风格做一个季度汇报 PPT」。

技能说明、模板与脚本见 `skills/guizang-ppt/`。
